# 포트폴리오 이미지

- 연수 사진·증서: 이 폴더에 이미지를 추가하고 `src/content.js`의 `gallery` 또는 `awards` 항목에 `image: 'assets/파일명.jpg'`와 대체 텍스트를 입력합니다.
- 지원 형식: png, jpg, jpeg, webp, avif, svg. 파일 확장자는 소문자를 사용합니다.
- 이미지 추가 후 `npm run build`로 다시 빌드합니다. Vite가 이미지를 빌드 결과에 포함합니다.
- 경력·학교·연수·수상 데이터와 이메일은 `src/content.js`에서 관리합니다. 확인된 정보만 추가합니다.
